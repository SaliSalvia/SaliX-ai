# Privacy Policy — SaliX-ai (Prototype)

_Last updated: 2026-11-02_

SaliX-ai is a **prototype/experiment-bed Android app**. It is not distributed to end users and has no production data flows yet.

## Commitments that apply now and at first functional release

- **No accounts, no analytics, no tracking** — the app has no backend of its own.
- **User-entered API keys stay on the device** and are sent only to the provider they belong to.
- **All local data (chat history, experiments) lives in app-private storage** and is deleted when the app is uninstalled.

## When features arrive

Every functional release must update this file **in the same PR** as the feature that touches personal data, following the pattern of the flagship repo (Personal-AI---HCN): a local-first, BYOK (bring your own key) model where nothing leaves the device except requests the user explicitly makes.
